1. RÉSUMÉ GÉNÉRAL
========================================================================

Le projet est un système complet de détection de fraude par ML.
Il utilise le dataset Kaggle "Credit Card Fraud Detection" (284 807 
transactions, ~0.17% de fraudes).

Stack technique:
- Python 3.11+
- scikit-learn / imbalanced-learn / XGBoost
- FastAPI (API REST)
- Streamlit (Frontend web)
- PostgreSQL (Historique)
- Docker Compose (Déploiement)

      (ou montés via volume ./models:/app/models)

  ⚠️ Nécessite LightGBM installé (pip install lightgbm)
  ⚠️ Exécution longue (~15-20 min pour tout le notebook)

DATASET
  ⚠️ Le fichier creditcard.csv (150 Mo) n'est PAS dans git
  ⚠️ Doit être téléchargé manuellement ou via kagglehub
  ⚠️ Nécessite un compte Kaggle pour le téléchargement auto

4. COMMENT LANCER LE PROJET
========================================================================

--- OPTION A: En local (sans Docker) ---

  1. Installer Python 3.11+
  2. cd fraud-detection
  3. python -m venv venv
  4. venv\Scripts\activate
  5. pip install -r requirements.txt
  6. Placer creditcard.csv dans data/raw/ (ou lancer train pour auto-download)
  7. python -m src.train          (5-10 min, entraîne le modèle)
  8. uvicorn api.main:app --reload --port 8000    (lance l'API)
  9. streamlit run webapp/app.py                   (lance le frontend)
  10. Ouvrir http://localhost:8501

  PostgreSQL (optionnel, pour l'historique):
  docker run -d --name fraud-db -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=fraud_detection -p 5432:5432 postgres:16-alpine


--- OPTION B: Avec Docker Compose (tout-en-un) ---

  1. Installer Docker Desktop
  2. cd fraud-detection
  3. S'assurer que models/best_model.joblib existe (sinon: python -m src.train)
  4. docker-compose up --build
  5. API:      http://localhost:8000
  6. Frontend: http://localhost:8501
  7. Swagger:  http://localhost:8000/docs
