\chapter{Validation, Tests et CI/CD}

\section{Tests Automatisés}

Les tests unitaires et d'intégration légère couvrent les points suivants:

\begin{itemize}
    \item nettoyage des données et scaling;
    \item génération des features attendues;
    \item endpoints \repoPath{/}, \repoPath{/health}, \repoPath{/metrics}, \repoPath{/model/info};
    \item erreurs API attendues: modèle absent, input invalide, batch vide;
    \item contrat de données et loader dataset.
\end{itemize}

\section{CI/CD}

La pipeline GitHub Actions \repoPath{.github/workflows/ci.yml} contient deux jobs:

\begin{enumerate}
    \item \textbf{test}: installation Python 3.11, dépendances, checks d'import, tests \repoPath{pytest}, \repoPath{dbt parse};
    \item \textbf{container-build}: construction de l'image Docker \repoPath{fraud-detection-mlops:ci}.
\end{enumerate}

Cette CI vérifie à la fois la cohérence applicative, la validité minimale du projet dbt et la capacité à construire l'image de déploiement.

\section{Commandes de Reproduction}

\begin{lstlisting}
cd fraud-detection
python -m dataops.ingestion
cd dbt_fraud && dbt build --profiles-dir . --project-dir . && cd ..
python -m src.train
python -m src.evaluate
pytest tests/ -q
docker-compose up --build
\end{lstlisting}
